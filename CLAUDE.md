# Rules

## "Make backup"
When the user says "make backup" (or similar), create a markdown (.md) file in `~/Documents/llm_briefs/` documenting what was done in the session. The file should:
- Be named descriptively with the date, e.g. `xfce-workspace-keybindings-2026-02-15.md`
- Include: date, machine info, what was changed, commands used, and any relevant notes
- Follow the format of existing files in that folder
- Note: Codex also commits briefs here — do not delete or rename existing files
