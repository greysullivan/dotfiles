COMMANDS

  air-theme charcoal --only firefox
    Generate/apply only the Firefox CSS and its enabling user.js preference.
    Other desktop components are not reloaded. Full air-theme charcoal also
    regenerates this Firefox theme from the same source.

  air-theme status
    Report applied Firefox configuration and refresh requirements.

  web [URL]
    Alias for firefox-detached, which uses the existing detached launcher.
    Open a new Zsh shell or run source ~/.zshrc to load the alias.

Activation requires Firefox's next normal restart. Current tabs, music and
browser processes were kept running. Launching web while Firefox is already
running does not reload CSS. Exit/restart normally when convenient.

ROLLBACK

  firefox-theme-rollback --check
    Validate restoration without changing live files.
  firefox-theme-rollback
    Restore the pre-restyle generator, Firefox CSS/user.js, alias, documentation
    and relevant tracking metadata. Mergeable unrelated edits are preserved.
    An overlapping edit or changed symlink aborts before any live restoration.
    Both versions of a conflicting file are retained privately in the backup.

The original preference was unset. If Firefox has loaded this theme, reset
  toolkit.legacyUserProfileCustomizations.stylesheets
in about:config after rollback, then restart normally. Removing user.js does
not erase a preference already persisted by Firefox. air-theme original is
whole-desktop baseline restoration; it is not the pre-restyle browser rollback.
